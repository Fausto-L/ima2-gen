# 006 노드 캔버스 UX — 템플릿, 팔레트, 호환 삽입

ima2 노드 캔버스는 기능적으로 이미 힉스필드 Canvas와 같은 부류다(그래프
라우팅, 세션 저장). 부족한 건 진입 장벽을 낮추는 UX 세 가지 — 전부
Freepik Spaces에서 검증된 패턴(서치 패턴 #4·#10·#13).

## 6-1. 빈 상태 = 3택 내비게이션

빈 노드 캔버스에 모달 튜토리얼 대신: **빈 캔버스로 시작 / 템플릿에서 시작 /
최근 그래프 이어가기**. 템플릿 카드는 결과물 이름으로("이미지 4변형 비교",
"참조→편집→I2V 파이프라인", "스타일 A/B", "캐릭터 시트").

## 6-2. 템플릿 시스템

- 그래프를 "템플릿으로 저장" — 노드 구조+설정은 남기고 미디어/결과물은
  비운 상태로 직렬화(기존 세션 직렬화 재사용, strip 단계만 추가).
- 시드 템플릿 4~6개 동봉. 템플릿 열기 = 사본 생성(원본 보존, 서치 패턴 #4의
  "copy, not execute").
- 저장 위치는 Assets 계층(004) `kind: template`.

## 6-3. 삽입 UX

- **커맨드 팔레트**: 캔버스에서 `/` 또는 Space → 노드 검색 삽입.
- **호환 필터 드래그**: 출력 포트를 빈 공간으로 드래그 → 연결 가능한
  다운스트림 노드만 필터된 선택기(잘못된 그래프를 만들 수 없게 하는 게
  학습 장치라는 근거 — 서치 패턴 #10).
- 미니맵 + fit-to-view 버튼(그래프가 커질 때 필수).

## 6-4. 분기 비교

같은 입력에서 프로바이더/설정만 다른 병렬 분기를 한 번에 만드는 "분기"
액션(Krea Nodes의 킬러 기능 — 서치 패턴 #11). 결과 노드들을 나란히 두고
눈으로 비교; ima2의 병렬 12건 큐가 이미 이걸 받쳐준다.

## 검증

- 템플릿 저장→복원 라운드트립 계약 테스트(미디어 strip 확인).
- 호환 필터 규칙 단위 테스트(포트 타입 매트릭스).
- 100+ 노드 그래프에서 팬/줌 프레임 드랍 프로파일.
